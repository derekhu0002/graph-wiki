# Contributing

> Authoritative source: [`community/CONTRIBUTING.md`](https://github.com/derekhu0002/graph-wiki/blob/main/community/CONTRIBUTING.md)

## Consume subgraphs

```jsonc
graph_list                                        // browse community subgraphs
graph_get { id: "abot-overseer-capability-001" }  // fetch a full graph
```

## Contribute a subgraph

1. **Trim** — cut an independently reusable fragment from your project's intent graph.
2. **Submit** — `graph_submit { id: "...", graph: {...}, name, version, description }`.
3. The service validates the schema automatically — if it passes, it is stored and committed.

Update with `graph_update { id: "...", graph: {...}, version: "1.1.0" }`.

## Conduct

- Submit only content you have the right to share.
- Never submit graphs containing sensitive information or secrets.
- Respect provenance: keep sourceRepo/sourceCommit when reusing another graph.
