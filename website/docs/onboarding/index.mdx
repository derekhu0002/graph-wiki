# 新项目接入（Onboarding）

本指南面向**刚起步的新项目**：如何从无到有把项目/知识图谱建起来，如何登记进**联邦**，以及加入后如何与联盟内的其它项目**共享知识、相互协作**。

## 三步走

1. **创建项目** —— 建立工作区与意图图谱（ArchiMate/本体的元素、关系、视图），跑通本地验收。
   → [从无到有创建项目](./create)
2. **加入联邦** —— 在中心登记成员身份，得到全局唯一的 `projectId`，并由中心构建你的**知识副本**。
   → [加入联邦](./join-federation)
3. **共享与协作** —— 授权他人读取、查询其它项目的知识、贡献子图，参与联邦协作。
   → [共享与协作](./collaborate)

## 术语速览

- **本体（ontology）**：图谱的类型体系与规则（如 ArchiMate 3.2）。见 [本体货架](/ontologies)。
- **意图图谱**：项目的架构与知识，落在 `design/KG/SystemArchitecture.json`。
- **联邦 / 联邦中心**：把多个自治项目组织起来、彼此按授权共享知识的机制。
- **projectId**：联邦中成员项目的全局唯一身份。
