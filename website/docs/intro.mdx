# ArchGraph — an architecture-graph framework for Agentic Engineering

**ArchGraph** builds a single, unified language that puts your harness design and your product design
into **one model**, so you work from one view — and keep real control over your agents.

## Core idea

```
Coding Agent  <->  ARGO MCP  <->  Intent graph (ArchiMate 3.2)  <->  Enterprise Architect
```

- **The intent graph is the source of truth** — the ArchiMate 3.2 model is the center of Agentic Engineering.
- **Harness-agnostic** — the ARGO toolchain distributes to GitHub Copilot / Cursor / OpenCode / DeepSeek
  Harness / OpenClaw.
- **Test-first** — executable GIVEN-WHEN-THEN acceptance; every commit is traced back to the graph.

## How it works

While working in a project, an agent automatically:

1. **Locate** — before changing anything, locate the architecture element behind the task in the intent graph.
2. **Arm** — load that element's Skills and Rules.
3. **Accept** — work test-first (GIVEN-WHEN-THEN); every commit is traced to the graph.

## Beyond one project: federation and the Graph Store

ArchGraph scales from **one project** to an **organization**:

- **Federation** — projects register as members, discover each other, and authorize knowledge sharing
  (default deny). See [Join the federation](/docs/onboarding/join-federation).
- **Graph Store** — an always-online center that hosts a queryable replica of each member's knowledge graph
  (projected into Neo4j with embeddings) and serves it through one query API, so any project can read another's
  knowledge (with authorization). See [Collaborate](/docs/onboarding/collaborate).
- **Ontologies** — ArchiMate 3.2 is the base ontology; the [ontology shelf](/ontologies) is extensible.

## Install

```bash
npm install -g archgraph-argo
argo-deploy
```

One command deploys the ARGO toolchain, skills and rules into GitHub Copilot / Cursor / OpenCode /
DeepSeek Harness / OpenClaw, and registers the `argo` MCP server.

> Semantic (Graph RAG) queries additionally need Neo4j and an embedding provider configured in
> ARGO's own `~/.argo/.env`; everything else works out of the box.
