# ArchiMate modeling language

**ArchiMate** is The Open Group's standard for enterprise-architecture modeling — and the modeling basis
behind ArchGraph's intent graph. To use ArchGraph well, understanding ArchiMate's elements, relationships
and views is essential.

## Why ArchGraph is built on ArchiMate

ArchGraph puts harness design and product design into **one model** (the intent graph); the "grammar" of
that model is ArchiMate 3.2.

- **One language** — express *who (Actor), what (capability/process), with what (application/technology),
  why (goal/principle)* using standard elements across the Business / Application / Technology / Motivation layers.
- **Relationship semantics** — Assignment / Realization / Serving / Access make the graph more than a set of
  nodes: it carries real structure and dependency meaning.
- **Layered viewpoints** — different views (Layered / Capability / Cooperation…) observe different facets of
  the same model.

## At a glance

```
Business     -> Actor / Role / Process / Service / Object
Application  -> Component / Interface / Function / Data Object
Technology   -> Node / Device / System Software / Artifact / Network
Motivation   -> Goal / Outcome / Principle / Requirement / Constraint
```

> The element types ArchGraph accepts are a legal subset of ArchiMate 3.2, and relationship types
> (Assignment/Realization/Serving/Access/Aggregation/Composition/Association/…) follow the ArchiMate 3.2
> relationship matrix. The service validates types and relationships automatically on subgraph submission.
