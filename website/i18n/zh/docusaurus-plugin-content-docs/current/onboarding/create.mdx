# 从无到有创建项目

一个新项目的第一步，是拥有自己的**意图图谱**（`design/KG/SystemArchitecture.json`）与本地工具链。

## 1. 初始化工作区（ARGO）

用 ArchGraph 的 ARGO 工具链初始化工作区，它会生成/校验图谱骨架、投影与语义索引：

- 运行 `argo-init`（ARGO MCP 的 `initializeWorkspace`）：bootstrap 工作区 + Neo4j 投影 + 语义生命周期（embedding）+ canonical 校验。
- 可用 Graph 项目（ArchGraph 框架）的 `initializeWorkspace` 确保环境就绪。

> 约束：Neo4j 需支持多 database（Enterprise）；embedding 走阿里 Qwen（键放 ARGO 自己的 `~/.argo/.env`）。

## 2. 建立意图图谱

图谱由三部分组成：**elements / relationships / views**。用 ARGO MCP 的变更工具增删改：

- `addArchitectureElement` / `updateArchitectureElement`
- `addArchitectureRelationship`
- `addArchitectureView`（视图挂在元素下，保持顶层视图唯一）

建议先列出业务要素（Actor/Capability/Service），再补关系与视图。

## 3. 本地验收（先测试、后实现）

为每个关键元素写**可执行的 GIVEN-WHEN-THEN 验收**，并用图谱校验 + 验收测试跑通：

- `validateSystemArchitecture`（schema/结构校验）
- `runArchitectureTests`（执行图中的验收用例）

> 规则：可端到端验证的必须端到端验证；正式验收在云端环境执行。

## 4.（可选）产出子图

把可复用的部分裁成**子图**（子图库用于社区共享，建设中）：`graph_submit` 提交到图谱库。
