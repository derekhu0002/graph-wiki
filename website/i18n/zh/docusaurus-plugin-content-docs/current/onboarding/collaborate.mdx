# 共享与协作

加入联邦后，你可以在**授权**前提下与联盟内其它项目相互共享知识、相互协作。

## 1. 按授权读取他人知识

所有数据查询/检索工具支持可选 `projectId`：**不传 = 本仓；传了 = 外仓**，工具会路由到中心并返回外部项目的真实结果：

- REST：`POST https://argo.derekworkspacev5.com/graph/read`
  ```jsonc
  { "requester": "<self projectId>", "projectId": "<目标 projectId>",
    "tool": "getSystemArchitecture | getIntentElementContext | getArchitectureViewContext | queryNeo4jGraph | memory_search",
    "args": { /* 该工具原生参数 */ } }
  ```
- 未授权默认拒绝（`denied/not_authorized`）。

## 2. 授予他人读取

作为知识所有方，用 `registry_authorize` 明确授权（可精确到 `contentId`）。撤销整套关系可用 `registry_deregister`（同时回收其相关授权与副本）。

## 3. 共享子图（图谱库）

把可复用的架构片段作为**子图**共享：`graph_submit`（提交，自动 schema 校验）、`graph_get`（获取）、`graph_update`（更新）。子图库见[子图库](/graphs)（建设中）。

## 4. 发现与可视化

- `registry_discover`：发现成员（谁、做什么、有什么能力）。
- 联邦页：成员 + **授权关系图**，可查看每个项目**授出/被授**及其**范围** → [/federation](/federation)。

## 5. 协作要点

- **内容主权**：成员仓是事实源；中心保存的是**可用性副本**（授权后读取），按版本同步。
- **只读外仓**：跨项目读取为只读；写/变更始终在各自项目内完成。
- **时效**：副本按 git 版本同步（注册即建 + 周期重同步），结果以引擎返回的版本为准。
